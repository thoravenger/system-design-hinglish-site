Har stream problem ka 4-step formula

Ulta socho: pehle jawab ka shape, phir baaki sab. Har problem ke left side me isi formula se soch likhi hai (practice mode me woh solution ke saath khulti hai).

O

Output ka shape

Jawab kis type ka hai? Number, String, List, Map, Optional ya boolean? Yahi terminal op decide karta hai.

T

Terminal op chuno

Shape ke hisaab se terminal op. Neeche ki table dekho.

S

Beech ke steps

filter (hatao), map (badlo), flatMap (kholo), distinct/sorted (unique, order), limit/skip (kaato).

E

Edge cases

Empty, null, duplicates, ties, order, case, overflow, paise.

Yaad rakhne ke liye: pehle plate (output), phir chulha (terminal), phir sabzi kaatna (steps), aakhir me namak check (edge cases).
