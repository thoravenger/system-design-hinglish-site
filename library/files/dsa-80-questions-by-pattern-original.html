1. Two Sum

LeetCode #1 · Easy

Given an array of integers nums and an integer target, return the indices of the two numbers that add up to target.

Each input has exactly one solution, and you may not use the same element twice. Return the answer in any order.

Example 1

Input: nums = [3, 8, 11, 5], target = 13
Output: [1, 3]

Explanation: nums[1] + nums[3] = 8 + 5 = 13.

Example 2

Input: nums = [-2, 7, 1, 9], target = -1
Output: [0, 2]

Example 3

Input: nums = [4, 4], target = 8
Output: [0, 1]

Constraints

  • 2 ≤ nums.length ≤ 10⁴

  • −10⁹ ≤ nums[i] ≤ 10⁹

  • −10⁹ ≤ target ≤ 10⁹

  • Exactly one valid answer exists.

Follow-up: Can you find an algorithm faster than O(n²)?

2. Three Sum (3Sum)

LeetCode #15 · Medium

Given an integer array nums, return all triplets [nums[i], nums[j], nums[k]] where i, j and k are different indices and nums[i] + nums[j] + nums[k] = 0.

The answer must not contain duplicate triplets. Return the triplets in any order.

Example 1

Input: nums = [-3, 1, 2, -1, 0, 1]
Output: [[-3, 1, 2], [-1, 0, 1]]

Explanation: These are the only distinct triplets that sum to 0. Using the second 1 gives the same triplets again, so it adds nothing.

Example 2

Input: nums = [1, 2, 3]
Output: []

Explanation: No three numbers sum to 0.

Example 3

Input: nums = [0, 0, 0, 0]
Output: [[0, 0, 0]]

Constraints

  • 3 ≤ nums.length ≤ 3000

  • −10⁵ ≤ nums[i] ≤ 10⁵

  • A node's right subtree holds only values strictly greater than the node's value.

  • Both subtrees are valid BSTs too.

Example 1

Input: root = [8, 4, 10, 2, 6]
Output: true

Example 2

Input: root = [8, 4, 10, 2, 9]
Output: false

Explanation: 9 is in the left subtree of 8, but 9 > 8.

  • −2³¹ ≤ Node.val ≤ 2³¹ − 1

25. Intersection of Two Linked Lists

LeetCode #160 · Easy

Given the heads of two singly linked lists, headA and headB, return the node where the two lists intersect. If they never intersect, return null.

Intersection means the same node by reference, not just an equal value. Neither list has a cycle, and both lists must keep their original structure after your function returns.

The judge builds the lists from these inputs, which your function does not receive:

  • intersectVal — the value of the first shared node (0 if there is none)

  • listA, listB — the two lists

  • skipA, skipB — how many nodes come before the shared node in each list

Example 1

Input: intersectVal = 8,
       listA = [3, 7, 8, 10], listB = [5, 8, 10],
       skipA = 2, skipB = 1
Output: Intersected at '8'

Explanation: Both lists share the tail 8 → 10. List A has 2 nodes before it; list B has 1.

Example 2

Input: intersectVal = 0,
       listA = [9, 3], listB = [6, 2, 7],
       skipA = 2, skipB = 3
Output: No intersection

Explanation: The lists never share a node, so return null.

Constraints

  • listA has m nodes and listB has n nodes, where 1 ≤ m, n ≤ 3 × 10⁴.

  • 1 ≤ Node.val ≤ 10⁵

  • 0 ≤ skipA ≤ m and 0 ≤ skipB ≤ n

  • intersectVal is 0 if the lists don't intersect; otherwise it equals listA[skipA] = listB[skipB].

Follow-up: Can you solve it in O(m + n) time with O(1) memory?
