map(): 1 in, 1 out

map har element ko badalta hai. Count same rehta hai, sirf value ya type badalti hai. Ek element se kai elements nikalne hon (jaise List of Lists), tab flatMap lagta hai.

Java ka Map process karna ho to uska entrySet() stream karo. Har element ek Map.Entry hota hai. Interview ka sabse common pattern:

// sabse zyada count wali key
String top = counts.entrySet().stream()Type: Stream<Entry<String, Long>>
.max(Map.Entry.comparingByValue())Type: Optional<Entry<String, Long>>
.map(Map.Entry::getKey)Type: Optional<String>
.orElse(null);Type: String

groupingBy: buckets banao

1 key → kai values. Default me har bucket ek List hoti hai.

List<String> words = List.of("apple", "avocado", "banana");
Map<Character, List<String>> m = words.stream()
    .collect(groupingBy(w -> w.charAt(0)));
// {a=[apple, avocado], b=[banana]}

Doosra argument (downstream) decide karta hai ki har bucket ke andar kya banega:

groupingBy(k, counting())Type: Map<K, Long>
groupingBy(k, mapping(f, toList()))Type: Map<K, List<R>>
groupingBy(k, summingInt(f))Type: Map<K, Integer>
groupingBy(k, TreeMap::new, toList())Type: TreeMap<K, List<T>>

Aakhri wale me keys sorted rehti hain.

Loop se jodo

groupingBy(key) andar se wahi karta hai jo loop me map.computeIfAbsent(key, x -> new ArrayList<>()).add(item) karta hai. Aur groupingBy(key, counting()) wahi karta hai jo map.merge(key, 1L, Long::sum) karta hai.

toMap: 1 key → 1 value

Map<String, Integer> total = orders.stream()
    .collect(toMap(o -> o.user,     // key
                   o -> o.amount,   // value
                   Integer::sum));  // same key aaye to jodo

Teesra argument (merge function) na ho aur same key dobara aaye, to exception aata hai. Order chahiye to chautha argument do: LinkedHashMap::new ya TreeMap::new.

Yaad rakhne ka tareeka: groupingBy = key ki list, toMap = key ki ek value. Asal me groupingBy(k, counting()) aur toMap(k, x -> 1L, Long::sum) same result dete hain.

Streams debugging: symptom se bug pehchano

Exception aaye to

Duplicate key
toMap me merge function missing hai.
NullPointerException (toMap me)
Koi value null hai. toMap null values allow nahi karta.
stream has already been operated upon or closed
Ek hi stream do baar use hua hai.
NoSuchElementException
Empty Optional pe .get() lagaya gaya hai.

Output galat aaye, par error nahi

a == b (boxed)
Do boxed Integer/Long ko == se compare kiya gaya hai. 127 se bade values pe ye false deta hai, isliye .equals() chahiye.
counting()
Ye Long deta hai, isliye count.equals(1) hamesha false hoga.
HashMap order
Order maan liya gaya hai. Sorted output ke liye TreeMap::new ya sorted() chahiye.
.reversed()
comparing(a).thenComparing(b).reversed() dono ko ulta kar deta hai, sirf b ko nahi.
Terminal operation missing
Streams lazy hote hain, isliye pipeline chala hi nahi.

Map methods kaise kaam karte hain

Ye saare methods sirf 2 cheezein check karte hain: key map me hai ya nahi, aur aapka function kya return karta hai.

Golden rule: function ne null return kiya to entry delete ho jaati hai, ya add hi nahi hoti.

MethodFunction kab chalta haiFunction ko kya milta hai
computeIfAbsentKey nahi hai tabkey
computeIfPresentKey hai tabkey, oldValue
computeHameshakey, oldValue (ya null)
mergeKey hai taboldValue, newValue

Neeche har line alag se m = {a=1} pe chalti hai.

getOrDefault aur putIfAbsent

m.getOrDefault("b", 0);  // 0 deta hai, par map abhi bhi {a=1}
m.putIfAbsent("a", 5);   // {a=1}, "a" pehle se hai
m.putIfAbsent("b", 5);   // {a=1, b=5}

computeIfAbsent

Key nahi hai tabhi function chalta hai. Ye current value return karta hai, isliye iske baad .add() chain kar sakte ho.

m.computeIfAbsent("a", k -> 99);    // {a=1}, function chala hi nahi
m.computeIfAbsent("b", k -> 99);    // {a=1, b=99}
m.computeIfAbsent("c", k -> null);  // {a=1}, null tha to add nahi hua

computeIfPresent

Key hai tabhi function chalta hai.

m.computeIfPresent("a", (k, v) -> v + 10);  // {a=11}
m.computeIfPresent("b", (k, v) -> v + 10);  // {a=1}, "b" hai hi nahi
m.computeIfPresent("a", (k, v) -> null);    // {}, "a" delete

compute

Function hamesha chalta hai. Key nahi hai to v null aata hai, aur uska check aapko khud karna hai.

m.compute("a", (k, v) -> v == null ? 1 : v + 1);  // {a=2}
m.compute("b", (k, v) -> v == null ? 1 : v + 1);  // {a=1, b=1}

merge

Key nahi hai to di hui value seedha daal deta hai, function nahi chalta. Key hai to function(oldValue, newValue) chalta hai. Yahan function ko key nahi milti.

m.merge("a", 5, Integer::sum);          // {a=6}
m.merge("b", 5, Integer::sum);          // {a=1, b=5}
m.merge("a", 5, (oldV, newV) -> null);  // {}, "a" delete

Asli code ke 4 patterns

// grouping
map.computeIfAbsent(dept, k -> new ArrayList<>()).add(emp);
// counting
map.merge(word, 1, Integer::sum);
// count ghatao, 0 hote hi key hatao
map.computeIfPresent(ch, (k, v) -> v == 1 ? null : v - 1);
// safe read
map.getOrDefault(word, 0);

Streams se connection: groupingBy andar se pehla pattern chalata hai, aur groupingBy(k, counting()) doosra. toMap(k, v, fn) bhi andar se merge() hi call karta hai. Isi wajah se toMap null value pe NPE deta hai.

Map debugging traps

putIfAbsent(k, new ArrayList<>()).add(x)
Pehli baar NPE dega. Key nahi thi, to putIfAbsent ne null return kiya.
getOrDefault(k, new ArrayList<>()).add(x)
Koi error nahi deta, par list map me kabhi jaati hi nahi. Data chupchaap gayab ho jaata hai.
compute(...) bina v == null check
Key na hone pe NPE aayega.
Function se null return
Galti se null return hua to entry chupchaap delete ho jaayegi.
computeIfAbsent ke andar map modify
Usi map ko function ke andar modify kiya (jaise recursive memoization me), to ConcurrentModificationException aata hai.

import java.util.*;
import java.util.function.*;
import java.util.stream.*;
import static java.util.stream.Collectors.*;

/*
 * PRACTICE 1: Page Visit Stats
 *
 * Each Visit is one page view: which user opened which page,
 * and how many seconds they stayed there.
 *
 * Some methods below have bugs (3 bugs in total).
 * Run the file, read the failing tests, and fix the code
 * so that ALL tests pass. Do not change the tests.
 *
 * Run (Java 11+):  java PageVisitStats.java
 */
public class PageVisitStats {

    static class Visit {
        final String user;
        final String page;
        final int seconds;

        Visit(String user, String page, int seconds) {
            this.user = user;
            this.page = page;
            this.seconds = seconds;
        }
    }

    /**
     * How many times each page was visited.
     * The map must be sorted by page name (A to Z).
     */
    static Map<String, Long> visitsPerPage(List<Visit> visits) {
        return visits.stream()
                .collect(groupingBy(v -> v.page, counting()));
    }

    /**
     * Total seconds each user spent on the site.
     */
    static Map<String, Integer> totalTimePerUser(List<Visit> visits) {
        return visits.stream()
                .collect(toMap(v -> v.user, v -> v.seconds));
    }

    /**
     * Users who visited the site exactly once, sorted A to Z.
     */
    static List<String> oneVisitUsers(List<Visit> visits) {
        return visits.stream()
                .collect(groupingBy(v -> v.user, counting()))
                .entrySet().stream()
                .filter(e -> e.getValue().equals(1))
                .map(Map.Entry::getKey)
                .sorted()
                .collect(toList());
    }

    /**
     * Distinct pages opened by the given user, sorted A to Z.
     */
    static List<String> pagesOf(List<Visit> visits, String user) {
        return visits.stream()
                .filter(v -> v.user.equals(user))
                .map(v -> v.page)
                .distinct()
                .sorted()
                .collect(toList());
    }

    // ==================== TESTS: do not change ====================

    static int passed = 0, failed = 0;

    static void check(String name, Object expected, Supplier<Object> actual) {
        try {
            Object got = actual.get();
            if (String.valueOf(expected).equals(String.valueOf(got))) {
                passed++;
                System.out.println("PASS  " + name);
            } else {
                failed++;
                System.out.println("FAIL  " + name);
                System.out.println("      expected: " + expected);
                System.out.println("      actual:   " + got);
            }
        } catch (Exception ex) {
            failed++;
            System.out.println("FAIL  " + name);
            System.out.println("      exception: " + ex);
        }
    }

    public static void main(String[] args) {
        List<Visit> visits = List.of(
                new Visit("ravi",  "home",    30),
                new Visit("neha",  "pricing", 45),
                new Visit("ravi",  "blog",    120),
                new Visit("amit",  "home",    15),
                new Visit("neha",  "home",    60),
                new Visit("kabir", "about",   20),
                new Visit("ravi",  "pricing", 10));
        List<Visit> oneVisit = List.of(new Visit("amit", "home", 15));
        List<Visit> repeatUser = List.of(
                new Visit("ravi", "home", 5),
                new Visit("ravi", "blog", 5));

        check("visitsPerPage: sample",
                "{about=1, blog=1, home=3, pricing=2}",
                () -> visitsPerPage(visits));
        check("visitsPerPage: one visit",
                "{home=1}",
                () -> visitsPerPage(oneVisit));
        check("totalTimePerUser: sample",
                "{amit=15, kabir=20, neha=105, ravi=160}",
                () -> new TreeMap<>(totalTimePerUser(visits)));
        check("totalTimePerUser: one visit",
                "{amit=15}",
                () -> new TreeMap<>(totalTimePerUser(oneVisit)));
        check("oneVisitUsers: sample",
                "[amit, kabir]",
                () -> oneVisitUsers(visits));
        check("oneVisitUsers: nobody",
                "[]",
                () -> oneVisitUsers(repeatUser));
        check("pagesOf: ravi",
                "[blog, home, pricing]",
                () -> pagesOf(visits, "ravi"));
        check("pagesOf: unknown user",
                "[]",
                () -> pagesOf(visits, "zoya"));

        System.out.println();
        System.out.println(passed + " passed, " + failed + " failed");
        if (failed == 0) System.out.println("ALL TESTS PASSED. Well done!");
    }
}

import java.util.*;
import java.util.function.*;
import java.util.stream.*;
import static java.util.stream.Collectors.*;

/*
 * PRACTICE 2: Game Leaderboard
 *
 * Each Score is one attempt: which player played which level,
 * and how many points they got.
 *
 * Some methods below have bugs (3 bugs in total).
 * Run the file, read the failing tests, and fix the code
 * so that ALL tests pass. Do not change the tests.
 *
 * Run (Java 11+):  java GameLeaderboard.java
 */
public class GameLeaderboard {

    static class Score {
        final String player;
        final int level;
        final int points;

        Score(String player, int level, int points) {
            this.player = player;
            this.level = level;
            this.points = points;
        }
    }

    /**
     * Players sorted by their TOTAL points, highest first.
     * If two players have the same total, sort them by name (A to Z).
     */
    static List<String> leaderboard(List<Score> scores) {
        Map<String, Integer> totals = scores.stream()
                .collect(groupingBy(s -> s.player, summingInt(s -> s.points)));

        Comparator<Map.Entry<String, Integer>> byPoints = Map.Entry.comparingByValue();
        Comparator<Map.Entry<String, Integer>> byName = Map.Entry.comparingByKey();

        return totals.entrySet().stream()
                .sorted(byPoints.thenComparing(byName).reversed())
                .map(Map.Entry::getKey)
                .collect(toList());
    }

    /**
     * Every player whose BEST single score equals the highest
     * single score in the game, sorted A to Z.
     * No scores -> empty list.
     */
    static List<String> topScorers(List<Score> scores) {
        Map<String, Integer> best = scores.stream()
                .collect(toMap(s -> s.player, s -> s.points, Math::max));

        Integer highest = best.values().stream()
                .max(Integer::compare)
                .orElse(null);

        return best.entrySet().stream()
                .filter(e -> e.getValue() == highest)
                .map(Map.Entry::getKey)
                .sorted()
                .collect(toList());
    }

    /**
     * The player with the most points on the given level.
     * If nobody played that level, return "" (empty string).
     */
    static String bestOfLevel(List<Score> scores, int level) {
        return scores.stream()
                .filter(s -> s.level == level)
                .max(Comparator.comparingInt(s -> s.points))
                .get()
                .player;
    }

    /**
     * Average points for each level, sorted by level number.
     */
    static Map<Integer, Double> averagePerLevel(List<Score> scores) {
        return scores.stream()
                .collect(groupingBy(s -> s.level, TreeMap::new,
                        averagingInt(s -> s.points)));
    }

    // ==================== TESTS: do not change ====================

    static int passed = 0, failed = 0;

    static void check(String name, Object expected, Supplier<Object> actual) {
        try {
            Object got = actual.get();
            if (String.valueOf(expected).equals(String.valueOf(got))) {
                passed++;
                System.out.println("PASS  " + name);
            } else {
                failed++;
                System.out.println("FAIL  " + name);
                System.out.println("      expected: " + expected);
                System.out.println("      actual:   " + got);
            }
        } catch (Exception ex) {
            failed++;
            System.out.println("FAIL  " + name);
            System.out.println("      exception: " + ex);
        }
    }

    public static void main(String[] args) {
        List<Score> scores = List.of(
                new Score("zoya",  1, 300),
                new Score("arjun", 1, 240),
                new Score("meera", 2, 500),
                new Score("arjun", 2, 500),
                new Score("zoya",  2, 200),
                new Score("dev",   1, 120));
        List<Score> noTies = List.of(
                new Score("amit", 1, 10),
                new Score("neha", 1, 20));
        List<Score> smallTie = List.of(
                new Score("amit", 1, 90),
                new Score("neha", 1, 90),
                new Score("ravi", 1, 50));

        check("leaderboard: no ties",
                "[neha, amit]",
                () -> leaderboard(noTies));
        check("leaderboard: with ties",
                "[arjun, meera, zoya, dev]",
                () -> leaderboard(scores));
        check("topScorers: small scores",
                "[amit, neha]",
                () -> topScorers(smallTie));
        check("topScorers: big scores",
                "[arjun, meera]",
                () -> topScorers(scores));
        check("topScorers: no scores",
                "[]",
                () -> topScorers(List.of()));
        check("bestOfLevel: level 1",
                "zoya",
                () -> bestOfLevel(scores, 1));
        check("bestOfLevel: nobody played",
                "",
                () -> bestOfLevel(scores, 3));
        check("averagePerLevel: sample",
                "{1=220.0, 2=400.0}",
                () -> averagePerLevel(scores));

        System.out.println();
        System.out.println(passed + " passed, " + failed + " failed");
        if (failed == 0) System.out.println("ALL TESTS PASSED. Well done!");
    }
}

Expert level tak practice plan

  1. Har collector ka loop version aur stream version side-by-side likho, aur dono ka output match karo.
  2. Koi bhi stream code padho to har line ke aage type likho, jab tak ye aadat na ban jaaye.
  3. Run karne se pehle output predict karo. Debugging round ka core skill yahi hai.
  4. Bugs khud code me daalo aur exception message dekho. Isse interview me message dekhte hi cause pakad loge.
  5. Bina IDE autocomplete ke practice karo. Ek candidate ke experience ke mutabik Karat me code compile aur run karwaya jaata hai, aur imports tak khud likhne pad sakte hain.
  6. Expert level ke liye flatMap, collectingAndThen, laziness aur short-circuiting (anyMatch, findFirst) seekho, aur khud ka Collector.of(...) likh ke dekho.
