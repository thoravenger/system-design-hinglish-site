    03
    Architecture
    

  

  

    

      
Doubly Linked List

      
Tracks access order. HEAD sentinel anchors the MRU end; TAIL sentinel anchors the LRU end. Every get/put moves the accessed node to HEAD.next — O(1) via direct pointer rewiring.

    

    

      
HashMap<K, Node>

      
Provides O(1) key → node lookup. Without it, finding a node in the linked list would be O(n). Together, HashMap + DLL give constant time for every operation.

    

    

      
Sentinel Nodes

      
Dummy head and tail nodes act as immovable anchors. They eliminate null-checks at list boundaries — insert always goes after head, eviction always removes tail.prev.

    

    

      
LinkedHashMap Alternative

      
Java's built-in LinkedHashMap with accessOrder=true provides LRU behavior out-of-the-box. Override removeEldestEntry() to auto-evict. The custom implementation teaches the internals.
