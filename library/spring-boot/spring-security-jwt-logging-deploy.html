JWT — Structure, Generation & Validation

JWT (JSON Web Token) is a compact, self-contained token for securely transmitting claims between parties. It has 3 parts separated by dots.

■ Header (algo + type) ■ Payload (claims: sub, roles, exp) ■ Signature (HMAC-SHA256 of header.payload) 
// ── JWT utility — generate + validate ────────────────────────────────
// Maven: io.jsonwebtoken:jjwt-api:0.12.5 + jjwt-impl + jjwt-jackson

@Component
public class JwtUtils {

    @Value("${jwt.secret}")
    private String secret;   // 256-bit base64 secret in application.yml

    @Value("${jwt.expiry-ms:900000}") // 15 min default
    private long expiryMs;

    private SecretKey key() {
        return Keys.hmacShaKeyFor(Decoders.BASE64.decode(secret));
    }

    // ── Generate access token ─────────────────────────────────────────
    public String generateToken(UserDetails user) {
        List<String> roles = user.getAuthorities().stream()
            .map(GrantedAuthority::getAuthority).toList();

        return Jwts.builder()
            .subject(user.getUsername())           // sub claim
            .claim("roles", roles)                  // custom claim
            .claim("type", "ACCESS")
            .issuedAt(new Date())
            .expiration(new Date(System.currentTimeMillis() + expiryMs))
            .signWith(key())                       // HMAC-SHA256
            .compact();
    }

    // ── Generate refresh token (longer lived) ─────────────────────────
    public String generateRefreshToken(String username) {
        return Jwts.builder()
            .subject(username)
            .claim("type", "REFRESH")
            .issuedAt(new Date())
            .expiration(new Date(System.currentTimeMillis() + 7L * 24 * 60 * 60000)) // 7 days
            .signWith(key())
            .compact();
    }

    // ── Validate and parse ────────────────────────────────────────────
    public Claims validateAndParse(String token) {
        return Jwts.parser()
            .verifyWith(key())
            .build()
            .parseSignedClaims(token)   // throws if expired/tampered
            .getPayload();
    }

    public String       getUsername(String token) { return validateAndParse(token).getSubject(); }
    public List<String> getRoles   (String token) { return validateAndParse(token).get("roles", List.class); }
    public boolean      isExpired  (String token) {
        try { validateAndParse(token); return false; }
        catch (ExpiredJwtException e) { return true; }
    }
}

Java 17 — JWT
Header

alg: HS256 (HMAC) or RS256 (RSA)
typ: JWT
Base64Url encoded

Payload (Claims)

sub: subject (userId)
iat: issued at
exp: expiry
roles: custom

Signature

HMAC-SHA256(base64(header) + "." + base64(payload), secretKey)
Prevents tampering

⚠️
JWT payload is base64-encoded, NOT encrypted. Anyone can decode and read it. Never put passwords, card numbers, or secrets in JWT. Use HTTPS always. Store tokens in HttpOnly cookies (not localStorage) to prevent XSS theft.

Authentication vs Authorization — Full Spring Flow

Authentication (who are you?)

Verifies identity. "Are you really Alice?"

  • Username + password → login endpoint
  • Server validates credentials → issues JWT
  • Client sends JWT in every subsequent request
  • Server validates JWT signature + expiry
Authorization (what can you do?)

Verifies permissions. "Can Alice delete orders?"

  • JWT contains roles: ["ADMIN","USER"]
  • Spring Security checks @PreAuthorize
  • Role-based: ADMIN can delete, USER cannot
  • Resource-based: can Alice access order #123?

// ── Login endpoint ────────────────────────────────────────────────────
public record LoginRequest(String username, String password) {}
public record LoginResponse(String accessToken, String refreshToken, String tokenType) {}

@RestController
@RequestMapping("/auth")
public class AuthController {

    private final AuthenticationManager authManager;
    private final JwtUtils              jwtUtils;

    @PostMapping("/login")
    public ResponseEntity<LoginResponse> login(@RequestBody LoginRequest req) {
        // 1. Authenticate — throws BadCredentialsException if wrong
        Authentication auth = authManager.authenticate(
            new UsernamePasswordAuthenticationToken(req.username(), req.password())
        );
        // 2. Get UserDetails from Authentication
        UserDetails user = (UserDetails) auth.getPrincipal();

        // 3. Issue tokens
        String access  = jwtUtils.generateToken(user);
        String refresh = jwtUtils.generateRefreshToken(user.getUsername());

        return ResponseEntity.ok(new LoginResponse(access, refresh, "Bearer"));
    }

    @PostMapping("/refresh")
    public ResponseEntity<LoginResponse> refresh(@RequestBody Map<String, String> body) {
        String refreshToken = body.get("refreshToken");
        Claims claims = jwtUtils.validateAndParse(refreshToken);
        if (!"REFRESH".equals(claims.get("type"))) throw new IllegalArgumentException("Not a refresh token");
        UserDetails user = userDetailsService.loadUserByUsername(claims.getSubject());
        String newAccess = jwtUtils.generateToken(user);
        return ResponseEntity.ok(new LoginResponse(newAccess, refreshToken, "Bearer"));
    }
}

// ── JWT Auth Filter — the most important custom filter ────────────────
@Component
public class JwtAuthFilter extends OncePerRequestFilter { // fires ONCE per request

    private final JwtUtils            jwtUtils;
    private final UserDetailsService  userDetailsService;

    @Override
    protected void doFilterInternal(
            HttpServletRequest  request,
            HttpServletResponse response,
            FilterChain         filterChain   // ← pass request down the chain
    ) throws ServletException, IOException {

        String authHeader = request.getHeader("Authorization");

        // 1. Skip if no Bearer token
        if (authHeader == null || !authHeader.startsWith("Bearer ")) {
            filterChain.doFilter(request, response); // ← MUST call this to continue chain
            return;
        }

        try {
            String token    = authHeader.substring(7);  // strip "Bearer "
            String username = jwtUtils.getUsername(token);

            // 2. Set authentication only if not already set
            if (username != null && SecurityContextHolder.getContext().getAuthentication() == null) {
                UserDetails user = userDetailsService.loadUserByUsername(username);

                // 3. Build authentication object with roles
                var auth = new UsernamePasswordAuthenticationToken(
                    user, null, user.getAuthorities()
                );
                auth.setDetails(new WebAuthenticationDetailsSource().buildDetails(request));

                // 4. Store in ThreadLocal SecurityContext
                SecurityContextHolder.getContext().setAuthentication(auth);
            }
        } catch (JwtException ex) {
            // Token invalid — clear context, let ExceptionTranslationFilter handle
            SecurityContextHolder.clearContext();
            response.sendError(HttpServletResponse.SC_UNAUTHORIZED, "Invalid token");
            return;
        }

        // 5. ALWAYS pass to next filter in chain
        filterChain.doFilter(request, response);
    }

    @Override
    protected boolean shouldNotFilter(HttpServletRequest req) {
        // Skip JWT filter for login, register, public endpoints
        String path = req.getServletPath();
        return path.startsWith("/auth/") || path.startsWith("/public/");
    }
}

// ── SecurityFilterChain Configuration ────────────────────────────────
@Configuration
@EnableWebSecurity
@EnableMethodSecurity          // enables @PreAuthorize, @PostAuthorize
public class SecurityConfig {

    private final JwtAuthFilter       jwtFilter;
    private final UserDetailsService  uds;

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        return http
            .csrf(AbstractHttpConfigurer::disable)       // stateless API, no CSRF needed
            .sessionManagement(s -> s.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/auth/**", "/public/**").permitAll()
                .requestMatchers("/admin/**").hasRole("ADMIN")
                .requestMatchers("/api/**").hasAnyRole("USER", "ADMIN")
                .anyRequest().authenticated()
            )
            .exceptionHandling(ex -> ex
                .authenticationEntryPoint((req, res, e) ->
                    res.sendError(401, "Unauthorized"))     // no token → 401
                .accessDeniedHandler((req, res, e) ->
                    res.sendError(403, "Forbidden"))          // wrong role → 403
            )
            .addFilterBefore(jwtFilter, UsernamePasswordAuthenticationFilter.class)
            .build();
    }

    @Bean
    public AuthenticationManager authManager(AuthenticationConfiguration config) throws Exception {
        return config.getAuthenticationManager();
    }

    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder(12);  // cost factor 12
    }
}

// Use this if you're on Spring WebFlux (reactive, non-blocking)
@Component
public class ReactiveJwtFilter implements WebFilter {

    @Override
    public Mono<Void> filter(ServerWebExchange exchange, WebFilterChain chain) {
        String token = exchange.getRequest().getHeaders()
            .getFirst("Authorization");

        if (token == null || !token.startsWith("Bearer "))
            return chain.filter(exchange);  // WebFilter uses chain.filter() not doFilter()

        return jwtUtils.validateReactive(token.substring(7))
            .flatMap(auth -> chain.filter(exchange)
                .contextWrite(ReactiveSecurityContextHolder.withAuthentication(auth)));
    }
}

AOP for Authorization — @PreAuthorize, Custom Aspects

// ── Method-level security with @PreAuthorize ──────────────────────────
@RestController
@RequestMapping("/api/orders")
public class OrderController {

    // Spring AOP proxy intercepts this call BEFORE method runs
    // SpEL expression evaluated against SecurityContext
    @PreAuthorize("hasRole('ADMIN')")
    @DeleteMapping("/{id}")
    public void delete(@PathVariable long id) { orderService.delete(id); }

    // Check role AND ownership: user can only access their own orders
    @PreAuthorize("hasRole('ADMIN') or @orderSecurity.isOwner(#id, authentication)")
    @GetMapping("/{id}")
    public Order get(@PathVariable long id) { return orderService.findById(id); }

    // @PostAuthorize — check AFTER method returns (filter return value)
    @PostAuthorize("returnObject.userId == authentication.name")
    @GetMapping("/my-latest")
    public Order myLatest() { return orderService.findLatestForCurrentUser(); }
}

// Custom security bean referenced in @PreAuthorize SpEL
@Component("orderSecurity")
public class OrderSecurityService {
    private final OrderRepository orderRepo;

    public boolean isOwner(long orderId, Authentication auth) {
        return orderRepo.findById(orderId)
            .map(o -> o.getUserId().equals(auth.getName()))
            .orElse(false);
    }
}

// ── Custom AOP Aspect for Authorization (advanced) ────────────────────
// Use when @PreAuthorize is not expressive enough

// 1. Custom annotation
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface RequiresPermission {
    String   resource();
    String[] actions();  // e.g. {"READ", "WRITE"}
}

// 2. Aspect that intercepts @RequiresPermission
@Aspect
@Component
public class PermissionAspect {

    private final PermissionService permService;

    @Around("@annotation(requiresPermission)")
    public Object checkPermission(ProceedingJoinPoint pjp, RequiresPermission rp) throws Throwable {
        Authentication auth = SecurityContextHolder.getContext().getAuthentication();

        if (auth == null || !auth.isAuthenticated())
            throw new AccessDeniedException("Not authenticated");

        String userId = auth.getName();
        boolean hasPermission = permService.hasAnyPermission(
            userId, rp.resource(), rp.actions()
        );

        if (!hasPermission) {
            log.warn("Access denied: user={} resource={} actions={}",
                userId, rp.resource(), rp.actions());
            throw new AccessDeniedException("Permission denied for " + rp.resource());
        }

        return pjp.proceed(); // call the actual method
    }
}

// 3. Usage

TraceId — Add Unique ID to Every Request & Log

// ── TraceId Filter — adds UUID to every request ───────────────────────
@Component
@Order(Ordered.HIGHEST_PRECEDENCE)  // must run FIRST
public class TraceIdFilter extends OncePerRequestFilter {

    public static final String TRACE_HEADER = "X-Trace-Id";
    public static final String MDC_KEY      = "traceId";

    @Override
    protected void doFilterInternal(HttpServletRequest req, HttpServletResponse res, FilterChain chain)
            throws ServletException, IOException {

        // Accept trace from upstream or generate new one
        String traceId = req.getHeader(TRACE_HEADER);
        if (traceId == null || traceId.isBlank())
            traceId = UUID.randomUUID().toString();

        try {
            // 1. Put in MDC — Logback/Log4j picks it up in every log line
            MDC.put(MDC_KEY, traceId);

            // 2. Echo it back in response header
            res.setHeader(TRACE_HEADER, traceId);

            // 3. Store in request attribute for controllers to use
            req.setAttribute(MDC_KEY, traceId);

            chain.doFilter(req, res);
        } finally {
            // CRITICAL: remove from MDC after request — thread pool reuses threads!
            MDC.remove(MDC_KEY);
        }
    }
}

// ── Propagate traceId to downstream services (RestTemplate/WebClient) ─
@Bean
public RestTemplate restTemplate() {
    RestTemplate rt = new RestTemplate();
    rt.getInterceptors().add((req, body, exec) -> {
        String traceId = MDC.get(TraceIdFilter.MDC_KEY);
        if (traceId != null) req.getHeaders().set(TraceIdFilter.TRACE_HEADER, traceId);
        return exec.execute(req, body);
    });
    return rt;
}

// WebClient propagation:
@Bean
public WebClient webClient() {
    return WebClient.builder()
        .filter((req, next) -> {
            String tid = MDC.get(TraceIdFilter.MDC_KEY);
            return next.exchange(ClientRequest.from(req)
                .header(TraceIdFilter.TRACE_HEADER, tid != null ? tid : "").build());
        })
        .build();
}

// ── Access Log Filter — saves every request/response to log ──────────
@Component
@Order(2)
public class AccessLogFilter extends OncePerRequestFilter {

    private static final Logger ACCESS_LOG = LoggerFactory.getLogger("ACCESS");

    @Override
    protected void doFilterInternal(HttpServletRequest req, HttpServletResponse res,
                                      FilterChain chain) throws ServletException, IOException {
        long start = System.currentTimeMillis();
        try {
            chain.doFilter(req, res);
        } finally {
            long durationMs = System.currentTimeMillis() - start;
            ACCESS_LOG.info("{} {} {} {}ms traceId={} userId={}",
                req.getMethod(), req.getRequestURI(),
                res.getStatus(), durationMs,
                MDC.get("traceId"),
                MDC.get("userId")
            );
        }
    }
}

// ── Custom Logback Kafka Appender ─────────────────────────────────────
public class KafkaLogAppender extends AppenderBase<ILoggingEvent> {

    private KafkaProducer<String, String> producer;
    private final String topic = "app-logs";
    private final ObjectMapper mapper = new ObjectMapper();

    @Override
    public void start() {
        Properties props = new Properties();
        props.put("bootstrap.servers", "broker1:9092");
        props.put("key.serializer",   "org.apache.kafka.common.serialization.StringSerializer");
        props.put("value.serializer", "org.apache.kafka.common.serialization.StringSerializer");
        props.put("linger.ms", "100");        // batch logs for efficiency
        props.put("compression.type", "gzip"); // logs compress very well
        producer = new KafkaProducer<>(props);
        super.start();
    }

    @Override
    protected void append(ILoggingEvent event) {
        try {
            Map<String, Object> logEntry = Map.of(
                "timestamp", event.getTimeStamp(),
                "level",     event.getLevel().toString(),
                "logger",    event.getLoggerName(),
                "message",   event.getFormattedMessage(),
                "traceId",   event.getMDCPropertyMap().getOrDefault("traceId", ""),
                "service",   "order-service",
                "host",      InetAddress.getLocalHost().getHostName()
            );
            String json = mapper.writeValueAsString(logEntry);
            producer.send(new ProducerRecord<>(topic, json));
        } catch (Exception e) {
            // Silent fail — don't let logging break the app
        }
    }

    @Override public void stop() { if (producer != null) producer.close(); super.stop(); }
}

// ── Kafka Consumer → Cassandra ────────────────────────────────────────
@Service
public class LogToCassandraConsumer {

    private final CassandraTemplate cassandra;
    private final ObjectMapper      mapper = new ObjectMapper();

    // Cassandra table: logs_by_service (partition: service+day, cluster: timestamp)
    @KafkaListener(topics = "app-logs", groupId = "log-processor",
                   concurrency = "3")
    public void consume(ConsumerRecord<String, String> record, Acknowledgment ack) {
        try {
            Map<String, Object> log = mapper.readValue(record.value(), Map.class);

            // Write to Cassandra — optimized for time-series log queries
            cassandra.insert(new LogEntry(
                (String) log.get("service"),
                LocalDate.now(),                    // partition key: service + day
                Instant.ofEpochMilli((Long) log.get("timestamp")),
                (String) log.get("level"),
                (String) log.get("traceId"),
                (String) log.get("message")
            ));
            ack.acknowledge();
        } catch (Exception e) {
            log.error("Failed to store log: {}", e.getMessage());
            // DLQ handles failed log entries
        }
    }
}

-- Cassandra table design for logs (optimized for: query by service + day + level)
CREATE TABLE logs_by_service (
    service     TEXT,
    log_date    DATE,
    timestamp   TIMESTAMP,
    level       TEXT,
    trace_id    TEXT,
    message     TEXT,
    PRIMARY KEY ((service, log_date), timestamp, level)
) WITH CLUSTERING ORDER BY (timestamp DESC)
  AND default_time_to_live = 7776000;  -- 90 days TTL auto-cleanup

-- Query logs: get all ERRORs for order-service today
SELECT * FROM logs_by_service
WHERE service='order-service' AND log_date='2024-01-15' AND level='ERROR'
ORDER BY timestamp DESC LIMIT 100;

            .logStreamName(logStream)
            .logEvents(events)
            .build());
    }
}

Blue-Green Deployment — Zero Downtime Release

Blue-Green keeps two identical environments. Blue is live. Green gets the new code. You switch traffic at the load balancer. If something breaks, flip back instantly.

Blue-Green Deployment Phases
PHASE 1
🔵 Blue (v1 LIVE — 100% traffic)
🟢 Green (v2 idle / deploying)
PHASE 2
🔵 Blue (100% traffic)
🟢 Green (v2 deployed + smoke tested)
PHASE 3
🔵 Blue (0% traffic, still running)
🟢 Green (v2 — 100% traffic)
PHASE 4
🔵 Blue (terminated / becomes next green)
🟢 Green (v2 LIVE — 100% traffic)
If v2 has a bug: flip LB back to Blue in seconds. Zero data loss.
# ── AWS ALB — blue-green with Target Groups ───────────────────────────

# Current state: Blue TG gets 100% traffic
aws elbv2 modify-rule \
  --rule-arn arn:aws:elasticloadbalancing:...rule/... \
  --actions '[{
    "Type": "forward",
    "ForwardConfig": {
      "TargetGroups": [
        {"TargetGroupArn": "arn:.../tg-blue", "Weight": 100},
        {"TargetGroupArn": "arn:.../tg-green","Weight": 0}
      ]
    }
  }]'

# Deploy new code to Green instances (Blue still serving all traffic)
# Run smoke tests on Green directly (bypass LB)
curl -H "Host: green.internal" http://green-instance:8080/actuator/health

# Switch to canary: 10% Green, 90% Blue (watch error rates)
--actions ForwardConfig.TargetGroups=[{tg-blue,Weight:90},{tg-green,Weight:10}]

# Full switch: 100% Green
--actions ForwardConfig.TargetGroups=[{tg-blue,Weight:0},{tg-green,Weight:100}]

# Rollback (instant — just flip weights back):
--actions ForwardConfig.TargetGroups=[{tg-blue,Weight:100},{tg-green,Weight:0}]

Graceful Shutdown — Let Existing Sessions Finish, Then Shutdown

When deploying new code, existing in-flight requests on the old instance must complete before it shuts down. No dropped requests, no 502 errors for active users.

Graceful Shutdown Sequence
1. Load Balancer removes old instance from target group (no new traffic)
2. SIGTERM sent to old instance JVM
3. Spring catches SIGTERM → starts shutdown sequence
4. Servlet container (Tomcat) waits for in-flight requests to complete
5. @PreDestroy / ApplicationListener<ContextClosedEvent> → cleanup
6. ThreadPools shut down gracefully (awaitTermination)
7. JVM exits cleanly — old instance is fully gone
# ── Spring Boot — enable graceful shutdown ────────────────────────────
# application.yml
server:
  shutdown: graceful              # default is "immediate" — CHANGE THIS!

spring:
  lifecycle:
    timeout-per-shutdown-phase: 30s  # wait up to 30s for requests to finish

application.yml
// ── What Spring's graceful shutdown does internally ───────────────────
// 1. Sets SmartLifecycle isRunning() = false
// 2. Tomcat connector: stop accepting new connections
// 3. Tomcat connector: waits for in-progress requests (up to timeout-per-shutdown-phase)
// 4. Spring context: calls stop() on all beans that implement Lifecycle
// 5. Spring context: closes — @PreDestroy methods fire, beans destroyed

// ── @PreDestroy — cleanup when Spring shuts down ──────────────────────
@Service
public class OrderProcessingService {

    private final ExecutorService workers = Executors.newFixedThreadPool(8);

    @PreDestroy
    public void cleanup() throws InterruptedException {
        log.info("Graceful shutdown: stopping worker threads...");
        workers.shutdown();  // no new tasks accepted
        if (!workers.awaitTermination(30, TimeUnit.SECONDS)) {
            log.warn("Workers didn't finish in 30s — forcing shutdown");
            workers.shutdownNow();
        }
        log.info("All workers stopped cleanly");
    }
}

// ── Kafka consumer — drain messages before shutdown ────────────────────
@Service
public class OrderKafkaConsumer implements ApplicationListener<ContextClosedEvent> {

    private volatile boolean shuttingDown = false;

    @Override
    public void onApplicationEvent(ContextClosedEvent event) {
        log.info("Context closing — consumer will drain and stop");
        shuttingDown = true;
    }

    @KafkaListener(topics = "orders")
    public void consume(Order order, Acknowledgment ack) {
        if (shuttingDown) {
            // Don't commit — will be reprocessed by new instance
            return;
        }
        processOrder(order);
        ack.acknowledge();
    }
}

# ── Kubernetes — readinessProbe + preStop hook ────────────────────────
spec:
  containers:
  - name: order-service
    lifecycle:
      preStop:
        exec:
          command: ["/bin/sh", "-c", "sleep 5"]
          # 5s sleep BEFORE SIGTERM: gives LB time to deregister instance
          # After preStop completes → SIGTERM sent → Spring graceful shutdown

    readinessProbe:
      httpGet:
        path: /actuator/health/readiness
        port: 8080
      initialDelaySeconds: 20     # wait before receiving traffic
      periodSeconds: 10
      failureThreshold: 3         # 30s to become unhealthy → removed from LB

    livenessProbe:
      httpGet:
        path: /actuator/health/liveness
        port: 8080
      initialDelaySeconds: 60
      periodSeconds: 30
      failureThreshold: 3         # 90s to fail → pod restarted

  terminationGracePeriodSeconds: 60  # max time for graceful shutdown before SIGKILL

# ── Full deploy sequence in Kubernetes ───────────────────────────────
# 1. kubectl apply -f deployment-green.yaml
# 2. K8s creates new green pods (using readinessProbe)
# 3. Once green pods are Ready → K8s switches service selector
# 4. Blue pods receive SIGTERM (preStop 5s delay → then 30s spring graceful)
# 5. In-flight requests on blue complete → blue pods exit
# 6. Done — zero dropped requests!

Kubernetes Graceful Shutdown
💡
The three keys to zero-downtime deploys:
  1. Readiness probe — new instance only gets traffic after it's truly ready
  2. Graceful shutdown — old instance finishes in-flight requests before dying
  3. preStop sleep — gives the load balancer time to deregister the old pod before SIGTERM is sent
Without all three, you'll see 502 errors during deployment.
