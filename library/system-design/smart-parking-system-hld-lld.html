07 — Design Patterns
Patterns Applied
Singleton
ParkingLot — One lot instance per JVM. Double-checked locking ensures thread-safe lazy initialisation.
Factory Method
VehicleFactory — Decouples vehicle creation from switch logic. Returns Bike / Car / Truck based on VehicleType enum.
Builder
ParkingLotBuilder — Fluent API: .addFloor(1,"Ground",10,20,5) makes lot configuration readable and testable.
Observer
ParkingEventListener — Decouple notifications, analytics, CCTV triggers. Register any number of listeners at runtime.
Strategy
FareCalculator — Pricing algorithm is isolated. Swap weekday vs weekend strategy, seasonal pricing, or subscription plans without touching core logic.
Template Method
Vehicle abstract class — Enforces getModel() contract while concrete subclasses (Bike, Car, Truck) provide their own model data.
08 — Bonus Features
Beyond the Requirements
EV Routing
Electric vehicles auto-routed to EV-charging spots. Falls back to regular spots if none available.
♿ Reserved Spots
First 2 small spots per floor reserved for differently-abled drivers. Flagged in status report.
🏠 Covered Parking
Indoor/covered spots have +₹5/hr surcharge and are preferred by some drivers.
Grace Period
First 30 minutes are completely free. Duration below threshold returns fare = ₹0.
Night Discount
25% discount automatically applied for midnight-6AM stays to encourage off-peak usage.
Lost Ticket
Flat ₹500 penalty. Spot freed, ticket archived as LOST status for audit trail.
Revenue Tracker
Real-time totalRevenue accumulation with completed ticket archive for daily reconciliation.
Vehicle Search
Find any parked vehicle by license plate across all floors in O(floors × spots) time.
