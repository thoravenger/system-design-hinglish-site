Run Postgres in Docker

You do not install Postgres yourself. Docker runs it, and the SQL file creates the Northline ledger the first time the volume is empty.

Steps

  1. Install Docker Desktop and wait until it says it is running.
  2. Open a terminal at the root of this repo. That is the folder that contains docker-compose.yml.
  3. Start the database.
docker compose up -d
docker compose ps
python python/weeks/week10_docker.py
python python/weeks/week07_sql.py

Look inside

docker compose exec db psql -U northline -d northline

Then type:

SELECT c.full_name, a.name, a.balance_cents
FROM accounts a
JOIN customers c ON c.id = a.customer_id;

Leave psql with \q.

Local password

User northline, password northline, database northline, port 5432. This is only for study on your machine. Do not reuse it.

Start over

The SQL runs only when the data volume is created. To wipe and reload:

docker compose down -v
docker compose up -d
