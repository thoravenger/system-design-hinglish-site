Run Python on your machine

Use a virtual environment. Do not install these packages into the Python that came with the operating system.

macOS or Linux

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r python/requirements.txt
python python/weeks/week01_syntax.py

Windows PowerShell

py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r python/requirements.txt
python python/weeks/week01_syntax.py

If PowerShell blocks the activate script, run it once: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

How to know it worked

Week 1 prints week 01 ok negative zero positive. Then run the bank tests:

python python/test_bank.py

Run the Python API later

After Docker is up:

cd python/northline
uvicorn main:app --reload --port 8090

Health check: http://127.0.0.1:8090/api/health
