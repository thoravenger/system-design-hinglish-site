You already know Spring. This repo teaches the same fintech system twice: once in Java 21 with Spring Boot and Spring AI, once in Python. Postgres runs in Docker. The HTML pages are the guide. The code is the practice.

Do this first

  1. Install Python 3.12, Java 21, Docker, and Maven.
  2. Open how to run Python and finish weeks 1 to 6. No database yet.
  3. Open how to run the database.
  4. Open Spring Boot and the Northline project.
  5. Use the week list as the order. Do not skip the file it names.

Open this folder with a tiny local server so the console page can call the API:

python -m http.server 5500

Then visit http://127.0.0.1:5500/ and start at this page. Run that command inside the guide folder.
