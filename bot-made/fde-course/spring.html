Java 21, Spring Boot, Spring AI

The project is java/northline. It is Spring Boot 3.5, Java 21, JDBC, and Spring AI 1.1. The database must already be running.

cd java/northline
mvn spring-boot:run

The app listens on port 8091. Check it:

curl http://127.0.0.1:8091/api/health

You should see "stack":"spring". If you see a database error, go back to the Docker page.

Call it as Ada

curl -H "X-Customer-Email: ada@northline.test" http://127.0.0.1:8091/api/accounts

Grok is the default model

Spring AI talks to Grok through the OpenAI-compatible endpoint at https://api.x.ai. The model is grok-4.7. The key belongs in the environment variable XAI_API_KEY, or in a .env file at the repo root. Git ignores that file. Do not commit the key.

export XAI_API_KEY=your-key
export NORTHLINE_AI_ENABLED=true
mvn spring-boot:run

On Windows use set instead of export. Offline answers still work when the flag is false.

To use OpenAI instead, unset XAI_API_KEY and set NORTHLINE_AI_PROVIDER=openai, NORTHLINE_AI_BASE_URL=https://api.openai.com, NORTHLINE_AI_MODEL=gpt-4o-mini, and OPENAI_API_KEY.

What to read in the Java

  • BankService is the ledger. The SQL is visible on purpose.
  • FinanceTools is what Spring AI is allowed to call.
  • SafeSql is the text-to-SQL guard. Only an advisor can run a report.
  • BankController is the HTTP surface. It matches the Python app.
