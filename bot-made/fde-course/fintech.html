Northline, end to end

Northline is a tiny consumer ledger. Ada has a checking account and a savings account. Grace is an advisor. Both the Spring app and the Python app use the same tables and the same rules.

Rules

  • Money is integer cents.
  • A transfer cannot overdraft, cannot use the same account twice, and needs a note above 200000 cents.
  • Ada sees only her accounts. Grace sees all of them. Send X-Customer-Email.
  • The assistant must call a tool for a balance. Offline mode does that without a model.

Python is port 8090. Spring is port 8091. Run one, or run both and compare.

A transfer

Python, port 8090. The fields are snake_case.

curl -H "Content-Type: application/json" -H "X-Customer-Email: ada@northline.test" \
  -d "{\"from_account_id\":1,\"to_account_id\":2,\"amount_cents\":500,\"note\":\"save\"}" \
  http://127.0.0.1:8090/api/transfers

Spring, port 8091. The same call, camelCase.

curl -H "Content-Type: application/json" -H "X-Customer-Email: ada@northline.test" \
  -d "{\"fromAccountId\":1,\"toAccountId\":2,\"amountCents\":500,\"note\":\"save\"}" \
  http://127.0.0.1:8091/api/transfers

On Windows PowerShell, use curl.exe and a single line. The rule underneath both calls is the same.

People

ada@northline.test is the customer. grace@northline.test is the advisor. Grace is the only one who can post a SELECT to /api/report.
